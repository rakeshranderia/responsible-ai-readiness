# Responsible AI Readiness

A lightweight interactive self-assessment for organisations considering operational AI use.

## Core model

**Data Governance → Trusted Data → AI Readiness → Responsible AI → Measurement → Scale**

## What it assesses

The tool covers:
- data ownership;
- classification;
- data quality;
- access;
- lineage;
- business purpose;
- risk assessment;
- approved platforms;
- human oversight;
- testing/evaluation;
- monitoring;
- Shadow AI controls.

## Outcomes

The assessment produces one of three simple outcomes:

- **Ready**
- **Ready with Controls**
- **Further Assessment Required**

This is deliberately a lightweight readiness indicator rather than a certification or formal compliance assessment.
